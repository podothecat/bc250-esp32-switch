PSU가 안 꺼지거나 늦게 꺼질 때: BC250 감지 전압과 전원이 꺼지는 과정을 봅니다.
컨트롤러를 켜도 BC250이 안 켜지거나, 끈 뒤 저절로 다시 켜질 때: 컨트롤러 신호를 봅니다.
설정 포털에서 컨트롤러가 목록에 안 나오거나 등록이 저장되지 않을 때: 등록이 어느 단계에서 멈췄는지 봅니다.

PC의 Chrome 또는 Edge로 이 파일을 열어 주세요. (Firefox, Safari, 휴대폰은 USB 시리얼을 지원하지 않습니다.)

처음 한 번: USB 드라이버 설치
ESP32 보드의 USB 칩(CP2102, Silicon Labs)은 드라이버가 자동으로 설치되지 않습니다. 이 PC에 보드를 처음 연결한다면 아래 순서대로 먼저 설치하세요. 이미 설치했다면 건너뜁니다.
  1. Silicon Labs 드라이버 페이지를 엽니다: CP210x USB to UART Bridge VCP Drivers
  2. Windows: [Downloads] 목록에서 "CP210x Universal Windows Driver"를 내려받아 압축을 풉니다. 풀린 폴더의 silabser.inf를 마우스 오른쪽 버튼으로 누르고 [설치]를 고릅니다. (Windows 11에서 메뉴에 없으면 [더 많은 옵션 표시] 안에 있습니다.)
  3. macOS: "CP210x VCP Mac OSX Driver"를 내려받아 설치하고, [시스템 설정 → 개인정보 보호 및 보안]에서 Silicon Labs 확장을 허용합니다.
  4. USB 케이블을 뽑았다 다시 꽂고, 이 페이지를 새로고침한 뒤 [연결]을 누릅니다.
  5. 그래도 목록이 비어 있으면: 시작 버튼을 마우스 오른쪽 버튼으로 눌러 [장치 관리자]를 엽니다. [포트(COM & LPT)] 아래에 "Silicon Labs CP210x USB to UART Bridge (COM3)"처럼 보이면 설치된 것입니다. [기타 장치]에 노란 느낌표가 붙은 "CP2102 USB to UART Bridge Controller"가 보이면 드라이버가 아직 설치되지 않은 것이니 2번을 다시 해 주세요. 아무 항목도 생기지 않으면 충전 전용 케이블일 수 있으니 다른 USB 케이블로 바꿔 보세요.
보드 연결
  1. ESP32 보드를 USB 케이블로 이 PC에 연결합니다. (BC250 전원 연결은 그대로 둡니다.)
  2. [연결]을 누르고 목록에서 포트를 고른 뒤 [연결]을 누릅니다.
  3. 아래에 [펌웨어 업데이트]가 노란 테두리로 나타나면 사용 방법을 따라 하기 전에 먼저 설치합니다.

사용 방법
  1. 이 창을 열어 둔 채로 BC250을 켜고, 평소처럼 사용하다가 종료합니다. 문제가 생길 때까지 반복해도 됩니다.
  2. 종료 후 1분 이상 기다립니다.
  3. [로그 저장]을 누르면 압축 파일(.zip)이 저장됩니다. 이 파일을 개발자에게 보내 주세요.
  1. BC250을 끄고 컨트롤러도 끈 채로 1분 기다립니다. 아래 [깨우기]가 "대기 중"이 되면 준비된 것입니다.
  2. 컨트롤러 전원을 켜고(Xbox 버튼, PlayStation은 PS 버튼만) 곧바로 [컨트롤러를 켰어요]를 누릅니다. 15초 뒤 결과가 진단 결과에 나옵니다.
  3. BC250이 켜졌다면 끄고, 컨트롤러도 끈 뒤 1번부터 몇 번 반복합니다. 저절로 다시 켜지는 문제라면 끈 뒤 2분 이상 그대로 둡니다.
  4. [로그 저장]을 누르면 압축 파일(.zip)이 저장됩니다. 이 파일을 개발자에게 보내 주세요.
  1. BC250이 꺼진 상태에서 포털 모드를 켭니다. 스위치나 ESP32의 BOOT 버튼을 스위치 LED가 빠르게 깜빡일 때까지 누른 뒤 놓습니다. 아래 [전원 상태]가 "설정 모드"가 됩니다.
  2. 휴대폰을 "BC250 Switch Setup" WiFi에 연결하고 http://192.168.4.1 에서 사용 설명서 순서대로 등록합니다. 그동안 이 창은 열어 둡니다. ESP32가 중간에 재부팅해도 기록은 이어집니다.
  3. 막히면 아래 [등록 진행]에서 어디까지 됐는지 확인하고, 그 화면에서 1분 정도 그대로 둔 뒤 [로그 저장]으로 파일을 보내 주세요.

깨우기는 BC250이 꺼져 있을 때만 동작합니다. 전원을 끈 직후에는 컨트롤러 신호가 30초 동안 조용해질 때까지 깨우기를 잠시 멈춥니다. 주변 BLE 신호는 근처 모든 기기의 신호 수로, BC250이 꺼져 있을 때만 측정됩니다.
